# 리소스 삭제 실습 (신설)

불필요한 리소스 삭제를 하는 실습입니다.

> ⚠️ **주의**
> - **오늘은 교육 마지막 날이므로 VPC까지 전부 삭제합니다.** 
> - 노드풀은 **퍼블릭 IP 연결부터 해제한 뒤** 삭제하고, **클러스터는 노드풀을 지운 뒤에만**, **VPC는 퍼블릭 IP·클러스터·File Storage를 모두 지운 뒤에만** 삭제할 수 있습니다.

1. AI Service > Kubeflow > Kubeflow 상세 화면 > 그룹/사용자 탭 > 추가했던 사용자/그룹 오른쪽 (...) 클릭 > 삭제 클릭 > 이름 입력 및 삭제버튼 클릭
2. AI Service > Kubeflow > 생성되어 있는 Kubeflow 오른쪽 (...) 클릭 > Kubeflow 삭제 클릭 > Kubeflow 이름 입력 및 삭제버튼 클릭
   - ※ 이 단계에서 Notebook, 파이프라인, 학습 Job, Katib, 모델 서빙 API 등 Kubeflow 내부 리소스는 함께 삭제되지만, **클러스터는 그대로 남습니다.**
3. Kubernetes Engine > 클러스터 > 클러스터 이름 클릭 > 노드 풀 탭 클릭 > 노드풀 오른쪽 (...) 클릭 > 퍼블릭 IP 연결 해제 클릭 > '연결 해제' 입력 > 연결 해제 버튼 클릭
4. 노드풀 오른쪽 (...) 클릭 > 삭제 클릭 > 영구 삭제 입력 및 삭제버튼 클릭
5. Kubernetes Engine > 클러스터 > 생성되어 있는 클러스터 오른쪽 (...) 클릭 > 클러스터 삭제 클릭 > 클러스터 이름 입력 및 삭제버튼 클릭
6. Storage > File Storage > Instance > 생성되어 있는 인스턴스 오른쪽 (...) 클릭 > Instance 삭제 클릭 > 인스턴스 이름 입력 및 삭제버튼 클릭
7. VPC > Public IP > 모두 선택 > 삭제버튼 클릭 > 영구 삭제 입력 > 삭제
8. VPC > 생성되어 있는 VPC 오른쪽 (...) 클릭 > VPC 삭제 클릭 > VPC 이름 입력 및 삭제버튼 클릭
